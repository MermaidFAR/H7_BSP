    QD4310 电机驱动

    QD4310 电机通过 FDCAN 接入 H7_BSP。本页说明初始化、反馈单位和命令接口；驱动位于 User_File/Device/Peripheral/Motor/QDrive/QD4310.h/.cpp。

    状态和单位

    QD4310_t 保存 enabled、id、speed（rpm）、angle（rad）、current（A）和 hfdcan。接收回调解码 8 字节反馈并更新这些字段。是否在线、实际动作以及电机型号边界仍须结合反馈与实机状态判断。

    命令接口

    接口 输入 返回
    QD4310_Enable/Disable(motor) 电机实例 bool，软件发送通道是否接受命令
    QD4310_SetCurrent(motor, current) ±10 A bool
    QD4310_SetSpeed/SetLowSpeed(motor, speed) ±1000 rpm bool
    QD4310_SetAngle(motor, angle) 0～2π rad bool
    QD4310_SetStepAngle(motor, step_angle) ±2π rad bool
    QD4310_SetZeroAngle(motor) 电机实例 bool

    QD4310_SendCommand() 把电流、速度、角度和低速控制写入周期最新值槽；使能、失能、步进角度、置零等动作进入顺序命令队列。接口返回 true 只表示软件通道接受提交，不代表硬件已发送或电机已执行。

    QD4310_t motor = {0};
QD4310_Init(&motor, 1, &hfdcan1);
bool accepted = QD4310_Enable(&motor);
if (accepted) {
    accepted = QD4310_SetSpeed(&motor, 500.0f);
}

    数值在驱动中被限幅并编码为协议值；使用前应确认电机型号、CAN ID、方向、量程和反馈。发送语义及总线确认边界见CAN 总线。
