    Yaw 速度环系统辨识与 PID 优化

    历史实验

    本文记录 2026 年 7 月一套云台 Yaw 速度环的辨识与调参过程，适合了解采样、建模和参数比较的方法。结果只适用于当时的硬件与任务配置；在当前 H7_BSP 上复用前，需要重新采样并实机调试。

    背景

    云台 Yaw 轴使用 QD4310 电机 + BMI088 IMU 组成速度闭环。原参数 K_P=0.035, K_I=0.348 存在换向响应慢、积分拖累等问题。通过 probe-rs + DAPLink 全自动调试管线完成了系统辨识和 PID 参数寻优。

    工具链

    环节 工具 说明
    调试探针 DAPLink (CMSIS-DAP) Horco CMSIS-DAP, FAED:4873
    闪存烧录 probe-rs v0.31.0 probe-rs download --chip STM32H723ZG
    数据采集 probe-rs attach RTT Channel 0, 100ms/帧
    系统辨识 Python scipy.optimize 时域参数化拟合
    PID 搜索 Python 闭环仿真 800 组网格搜索

    表中的 STM32H723ZG 是原实验使用的芯片参数，当前板型为 STM32H723VGT6；烧录时请按实际芯片重新选择。

    数据采集

    固件注入多激励信号序列（35s），通过 SEGGER RTT 实时输出目标速度、实测速度、PID 输出和陀螺原始值：

    激励设计:
  0-5s:   恒速 2 rad/s (DC 稳态)
  5-15s:  PRBS ±4 rad/s (1s 切换周期, 宽频带激励)
  15-25s: Chirp 0.2→20Hz, ±2 rad/s (频率响应验证)
  25-30s: 多幅值阶跃 [1, 1.5, -2, 2.5] rad/s
  30-35s: 恒速 2 rad/s

    probe-rs attach --chip STM32H723ZG 通过 DAPLink 读取 RTT Channel 0，持续 40s，获得 393 帧实测数据。

    系统辨识

    数据分区

    • 辨识区 (5-15s): PRBS 宽频激励 — 用于模型拟合
    • 验证区 (15-25s): Chirp 扫频 — 交叉验证
    • 验证区 (25-30s): 多幅值阶跃 — 额外验证

    模型结构

    速度闭环建模为一阶惯性 + 纯延迟：

    \[ G(s) = K \cdot \frac{e^{-Ls}}{\tau s + 1} \]

    拟合方法

    时域参数化拟合。用 scipy.optimize.minimize（L-BFGS-B 有界优化）， 同时最小化辨识区和验证区的 NRMSE：

    \[ \text{Loss} = \sum_{i} \left( y_{\text{meas},i} - y_{\text{pred},i}(K,\tau,L) \right)^2 \]

    该次仿真对被控对象采用双线性变换（Tustin）离散化；这不说明当前嵌入式 alg_pid.cpp 使用相同离散化方法。

    辨识结果

    参数 值 说明
    K 1.051 直流增益
    τ 0.108 s 时间常数
    fc 1.47 Hz 截止频率 \(f_c = 1/(2\pi\tau)\)
    L 30 ms 等效纯延迟
    Chirp NRMSE 15.4% 模型预测 vs 实测

    传递函数：

    \[ \boxed{G(s) = 1.051 \cdot \frac{e^{-0.03s}}{0.108s + 1}} \]

    延迟拆解：CAN 通信 ~5ms + 电机机械惯性 ~25ms（FIR 滤波器已移除）。

    PID 参数寻优

    方法

    在识别出的被控对象模型上，模拟完整闭环（PID + 死区 + 积分限幅 + 输出限幅）， 对 800 组 (K_P, K_I) 组合做网格搜索，用 Chirp 区段 NRMSE 评分。

    搜索范围

    • K_P: 0.06 ~ 0.15 (步长 0.01)
    • K_I: 0.25 ~ 0.63 (步长 0.02)
    • K_D: 固定为 0（一阶被控对象无 D 需求）

    结果

    档位 K_P K_I Chirp NRMSE PRBS NRMSE Step NRMSE
    原始 (bug 修复前) 0.035 0.348 — — —
    保守 0.070 0.348 31.7% 40.9% 31.2%
    推荐 0.100 0.500 30.6% 38.6% 30.4%
    激进 (理论最优) 0.150 0.630 29.0% 35.9% 29.2%

    结论：K_P 0.10~0.15, K_I 0.50~0.63，NRMSE 随增益单调下降。 物理约束为 Out_Max=1.65A，过高的 K_P 会导致输出饱和从而恶化响应。

    实测验证说明

    网格搜索在识别出的被控对象模型上进行，未烧录每组参数到实物实测。 建议烧录 K_P=0.10/K_I=0.50 实测，如果电机不抖、不发烫，可逐步提高到 K_P=0.15/K_I=0.63。

    Bug 修复

    Set_Now 未初始化变量

    当时的文件位置：alg_filter_frequency.h（旧版本行号不再适用）。

    Class_Filter_Frequency::Set_Now() 中局部变量 now_value 未初始化。 当 Init(0.0f, 0.0f, ...) 时，if 条件永不成立，now_value 保持栈上垃圾值， 导致滤波器缓冲区写入随机数据。

    当时的绕过方法：改用 Init(-1e10f, 1e10f, ...)。当前 Set_Now() 已先将输入赋给 now_value，两项限幅均为零时按接口约定不限幅；不能把历史绕过方法继续当成当前接入要求。

    FIR 滤波器移除

    通过 PSD 分析确认 BMI088 陀螺仪原始数据在 1-500Hz 频段无显著噪声， 20 阶 FIR 低通滤波器（60Hz 截止, 10ms 延迟）滤波前后频谱完全重合，噪声衰减为 0%。 已移除滤波器，陀螺原始值直接送入 PID，省去无意义延迟。
