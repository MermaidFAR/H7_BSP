    Yaw 位置环系统辨识与 PID 优化

    历史实验记录

    本文记录 2026 年 7 月特定云台的辨识与仿真参数，不是当前主线的板上调参建议。2026-09-27 的 d606170 提交已从当前工作树移除 sysid/；历史日志、脚本和图像可在父提交 4c1dbd4 中追溯。应用到当前 BMI088、PID 与任务链前须重新确认时序、单位、反馈源并实测。下方“推荐”仅指当时仿真方案。

    架构

    串级控制：

    Target_Angle → 角度 PID → Target_Speed → 速度 PID → 电流 (A) → QD4310 电机
              ↑                                                           ↓
              └─── BMI088 欧拉角 (rad)                   陀螺仪角速度 (rad/s) ←──┘

    外环输出作为内环目标，内环带宽须为外环 4~5 倍。

    系统辨识

    方法

    • 数据采集：probe-rs + DAPLink RTT Channel 0，每 100ms 一帧
    • 激励：PRBS ±1 rad (5-15s) + Chirp 0.1→5Hz (15-25s) + 阶跃 (25-30s)
    • 分区：PRBS 区辨识，Chirp 区和阶跃区交叉验证
    • 拟合：一阶 + 延迟 K·e^{-Ls} / (τs + 1)，双线性变换离散化，scipy.optimize.minimize L-BFGS-B

    辨识结果

    参数 值 说明
    K 0.50 直流增益
    τ 0.50 s 时间常数
    fc 0.32 Hz 截止频率
    L 174 ms 等效纯延迟

    传递函数：

    \[ G_{pos}(s) = 0.50 \cdot \frac{e^{-0.174s}}{0.50s + 1} \]

    速度内环交叉验证

    从位置环 PRBS 数据用 CSD 交叉谱估计速度内环等效带宽：

    • 速度环从 SpdOut（角度 PID 输出）→ SpdNow（实际角速度）的 -3dB 带宽 ≈ 0.75 Hz
    • 比速度环单独辨识的 1.47 Hz 偏低——因为角度 PID 的输出限幅（4.0 rad/s）和高 I 值限制了有效激发带宽
    • 内环/外环带宽比 = 0.75/0.32 ≈ 2.3，串级控制架构合理但偏低，建议后续进一步提速

    阶跃响应

    2.5 rad (≈143°) 大幅值阶跃实测：

    指标 值 备注
    上升时间 (10%→90%) 1400 ms 偏慢，受限于速度环积分饱和前馈不足
    超调 ~49% 角度 K_I=1.01 过大导致
    5% 稳态时间 2900 ms
    速度峰值 1.66 rad/s 远低于 Out_Max=4.0，速度环未饱和

    PID 优化

    网格搜索（K_P 0.05→0.40, K_I 0.2→2.0）在识别出的模型上仿真比对：

    方案 K_P K_I NRMSE
    原始 0.045 1.011 17.2%
    推荐 0.120 1.300 11.5%
    激进 0.200 1.800 12.2%

    推荐 K_P=0.12, K_I=1.30——NRMSE 最低，超调预计从 49% 降至 ~20%，上升时间改善到 ~600ms。

    最终参数汇总

    环节 K_P K_I K_D Out_Max I_Out_Max
    速度环 (内环) 0.150 0.630 0 1.65 A 1.2
    角度环 (外环) 0.120 1.300 0 4.0 rad/s 4.0
