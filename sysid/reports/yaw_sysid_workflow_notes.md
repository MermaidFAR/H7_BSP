# Yaw 云台系统辨识经验：从数据采集到参数优化

## 核心流程

**明确控制对象**

- 先分清输入和输出。速度环是 `Target_Yaw_Speed -> Gyro_Z/Yaw rate`，位置环是 `Target_Yaw_Angle -> Euler_Yaw`。
- 位置环的内层执行对象不是普通一阶低通，而是“速度闭环 × 积分器”。角度来自速度积分，模型结构必须体现 `1/s`。
- `Pre_Now` 是当前位置/当前速度，不是误差。`Pre_Out` 是上一拍控制输出，不能随手当成目标。

**设计激励**

- PRBS 用于辨识主动态，阶跃用于看上升、超调、稳态误差，chirp 用于频响验证。
- 激励幅值要覆盖真实工作区间。位置环 `Kp=10` 后速度目标峰值已到约 `24rad/s`，旧 `±2.5rad/s` 速度环数据不够代表真实负载。
- 阶跃保持时间必须够长，否则还没进入稳态就换目标，只能评价“跟随快慢”，不适合估稳态误差。

**采集数据**

- RTT 文本帧适合快速迭代，格式要固定，方便正则解析。
- 位置环至少记录：`Angle Tgt/Now/Err/SpdOut/SpdNow/YawOut`。
- 速度环至少记录：`YawSpd Tgt/Now/Err/Out/IOut`，最好再加原始 gyro 和滤波后 gyro。
- 10Hz RTT 能看宏观阶跃，但对 1kHz PID 偏稀疏。速度环下一轮建议提高到 50~100Hz。

**清洗与分段**

- PRBS、chirp、step 分段分析，不要把整段混成一个指标。
- 指标至少包括 RMSE、MAE、90% 到达时间、中位超调、P90 超调、稳定时间、输出峰值。
- 输出峰值和饱和比例必须看，否则“误差小”可能只是靠过大指令硬怼。

**系统辨识**

- 一阶加延迟模型可作为速度闭环的第一近似：`K * exp(-Ls) / (tau*s + 1)`。
- 拟合参数必须加物理边界，避免出现负时间常数、负延迟等数学上能拟合但物理上无意义的结果。
- MATLAB 的 `tfest/ssest/arx/oe` 结果要看验证集 fit，不要只看训练集。
- 如果模型给出荒唐 PID，例如旧脚本算出 `Kp≈14, Ki≈29`，优先怀疑量纲、对象定义或数据工况，而不是直接相信优化器。

**参数优化**

- 先用模型缩小候选范围，再用实机 RTT 三组以上对比。
- 位置环最终实测：`Kp=10, Ki=0` 优于 `Kp=7, Ki=1`。这是在修复外环重复计算 bug 后成立的结论。
- 当前无磁力计 yaw 会漂，位置环积分可能追漂或积累误差；短期位置环先用纯 P 更稳。
- 速度环仍有优化空间，但必须重新采当前 `Kp=0.15, Ki=0.63` 参数下的大幅值数据。

## 当前数据可信度

**速度环 legacy 数据**

- 文件：`speed_loop/data/speed_loop_legacy_sysid_data.csv`
- 模型：`G_spd(s) = 1.051 * exp(-30ms*s) / (0.108s + 1)`
- 结论：能说明速度环闭环带宽偏保守，执行余量较大。
- 限制：不代表当前固件参数，不能直接用于当前参数优化。

**位置环新数据**

- 文件：`position_loop/logs/rtt_angle_sysid_kp10_ki0.log`
- 结论：`Kp=10, Ki=0` 在三组实测中最好。
- 指标：RMSE 约 `0.374rad`，MAE 约 `0.149rad`，90% 到达中位约 `0.2s`，P90 超调约 `2.35%`。

## 下一步建议

- 重新设计速度环采集：`±5 / ±10 / ±20rad/s` PRBS + 多幅值阶跃。
- 提升 RTT 采样频率到 50~100Hz，或改用更紧凑的二进制/JustFloat 数据通道。
- 速度环先试探 `Kp=0.20~0.30`、`Ki=0.8~1.2` 的保守范围，但必须用实机对比，不直接写死。
- 长时间静止测试 yaw 漂移，判断位置环纯 P 在真实目标跟踪中的静态误差是否可接受。
